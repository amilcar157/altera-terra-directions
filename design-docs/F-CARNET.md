# F · Carnet de Voyage

**Concept.** A luxury travel magazine, not a brand site: a cover treatment, a contents-style strip, multi-column articles with pull-quotes and photo captions set in small caps. The journey is told as a feature story, not a product page.

**Palette** (roles)
- `#FBF9F4` Newsprint — page background, warmer white than D
- `#1F2430` Ink-blue — headings, rules, the "masthead" color
- `#A23E2E` Rouge — the single editorial accent (section labels, pull-quote marks)
- `#4A4A44` Slate — body text, captions

**Typography.** `Playfair Display` for headlines (true magazine-serif drama, high contrast); `Source Serif 4` for the running body text (a serif built for long-form reading, not a sans); `Inter` only for captions, bylines, and the nav — the one sans in the system, used sparingly so it reads as "caption," not UI chrome.

**Recurring motif.** A thin double rule (Ink-blue, 2px + 1px with a gap) under every headline — the masthead rule — and a large Rouge drop-cap-style numeral or opening quotation mark introducing each major section, standing in for iconography.

**Image style.** Documentary travel photography with a strong sense of place and light — gardens, savanna, a table set for the evening — captioned in italics underneath, the way a magazine credits a shot.

**Three key decisions.**
1. The Home is laid out as a contents page: a "cover" hero (headline + standfirst over a single image, magazine-style) followed by sections set in a two-column grid at desktop width (image left or right, text in a serif column), collapsing to a single column on mobile.
2. Every image carries a visible caption line (not just `alt`) — "Nisyros, the Cyclades" — reinforcing the editorial voice and giving a second, skimmable layer of content that also helps SEO.
3. The five pillars are presented as a numbered "contents" list (I–V) rather than cards or icons, echoing a magazine's table of contents and avoiding any card/shadow anti-pattern.
